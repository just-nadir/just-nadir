# Nodir

Full-stack developer. [NadPOS](https://nadpos.uz)ni yozaman — O'zbekiston restoranlari uchun POS tizimi: kassa, backend, boshqaruv panellari, yetkazib berish boti — bittasi yagona repoda emas, yettita alohida ilova sifatida.

Stack: NestJS, React, Electron, PostgreSQL, Prisma, SQLite.

---

**Hozir nima ustida ishlayapman**

- POS kassa oflayn ishlaydi — internet uzilsa ham savdo to'xtamaydi, keyin backend bilan sinxronlanadi
- Restoranlarning litsenziya/obuna tizimi — Click.uz va Payme orqali avtomatik to'lov
- Telegram orqali yetkazib berish boti — har restoranning o'z boti bilan

**Nega shu yo'lni tanladim**

Restoran egalari uchun oddiy, tez va ishonchli dastur kerak — bulutga bog'lanib qolmaydigan, internet o'chsa ham ishlayveradigan. Shuning uchun POS qismi Electron + SQLite, backend esa faqat hisobot va litsenziya uchun.
